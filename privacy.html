Política de Privacidad — Arisu Bot

Fecha de vigencia: 4 de octubre de 2026

1. Responsable

Esta política describe cómo Emanuel Avalos (“nosotros”) trata datos al operar el bot de Discord Arisu (Arisu#9797, aplicación 1556527373678018570). El bot es un proyecto de hobby, no comercial.

2. Qué datos se procesan

Solo cuando alguien menciona al bot o responde a uno de sus mensajes, Arisu puede leer:

  • El contenido del mensaje que lo activa (texto, adjuntos relevantes como CSV, y metadatos básicos como ID de usuario, canal y servidor).
  • El mensaje al que se está respondiendo (incluido el contenido de embeds, por ejemplo de Mudae).
  • Hasta aproximadamente los últimos 15 mensajes recientes del canal, para contexto o para armar gráficas.

También mantiene en memoria (RAM) las últimas ~10 interacciones por canal para continuar la conversación. Esa memoria se borra al reiniciar el bot y no se guarda en disco como historial de chat.

Los logs técnicos del servidor donde corre el bot pueden incluir nombres de usuario, IDs de servidor/canal y mensajes de error, solo para depuración.

3. Para qué se usan

  • Generar la respuesta solicitada (chat, gráfica o búsqueda).
  • Mantener un contexto corto de conversación.
  • Diagnosticar fallos.

No vendemos datos, no mostramos publicidad y no usamos trackers de marketing.

4. Con quién se comparten (encargados / terceros)

  • Discord: la plataforma por la que se envían y reciben mensajes.
  • MiniMax (api.minimax.io): recibe el texto necesario para generar la respuesta de IA.
  • DuckDuckGo: cuando pides una búsqueda web o de imágenes, la consulta se envía a ese servicio.
  • YouTube / Google: cuando pides un video, se consulta YouTube para encontrar resultados.
  • Pixiv, AniList y Steam: cuando pides ilustraciones, fichas de anime/manga, juegos o perfiles públicos de Steam, la búsqueda se envía a esos servicios.
  • Bilibili, Twitch (a través de decapi.me), TikTok, YouTube y Bluesky: cuando pides videos de Bilibili o un perfil público de esas plataformas, el nombre buscado se envía a esos servicios. Solo se muestran datos públicos y no se guardan.

Esos servicios tienen sus propias políticas de privacidad. No controlamos cómo las aplican.

5. Conservación

El historial de chat en memoria se pierde al reiniciar. Los logs técnicos se conservan un tiempo limitado en el servidor privado donde corre el bot, solo para operación y depuración.

6. Menores

El bot no está dirigido a menores de 13 años (edad mínima de Discord). Si eres padre/madre o tutor y crees que un menor nos envió datos de forma indebida, contáctanos para borrarlos.

7. Tus opciones

Puedes dejar de usar el bot, pedirle a un administrador que lo quite del servidor, o solicitar borrado de logs/datos que aún conservemos abriendo un issue en github.com/remasterzerouvm/arisu-bot-legal.

8. Cambios

Podemos actualizar esta política. La fecha de vigencia al inicio indica la versión actual.

Privacy Policy — Arisu Bot

Effective date: October 4, 2026

This policy describes how Emanuel Avalos (“we”) handles data when operating the Discord bot Arisu (Arisu#9797, application ID 1556527373678018570), a personal/non-commercial hobby project.

Only when the bot is @mentioned or someone replies to its messages may it read the triggering message (text, relevant attachments, and basic IDs), the replied-to message (including embeds such as Mudae’s), and about the last 15 recent channel messages for context/charts. It keeps the last ~10 exchanges per channel in RAM for short context; that memory is cleared on restart and is not stored as chat history on disk. Host logs may include usernames, server/channel IDs, and errors for debugging.

Data is used to fulfill the request (chat, chart, or search), keep short conversational context, and debug failures. We do not sell data, show ads, or use marketing trackers.

Third parties involved: Discord (messaging), MiniMax (AI responses), DuckDuckGo (web/image search when requested), YouTube/Google (video search when requested), and Pixiv / AniList / Steam (illustration, anime/manga, game and public profile lookups when requested), and Bilibili / Twitch (via decapi.me) / TikTok / YouTube / Bluesky (Bilibili video search and public profile cards when requested; only public data is shown and nothing is stored). Those services have their own privacy policies.

The bot is not directed at children under 13. To stop using it, remove it from the server or open an issue at github.com/remasterzerouvm/arisu-bot-legal to request deletion of retained logs/data we still hold.
